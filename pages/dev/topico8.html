🧠 Lógica e Provas — Pensar como a Máquina Exige

Proposições, implicação, e as técnicas de prova — com a indução trabalhada de verdade. O alicerce invisível de tipos, testes, invariantes e recursão.

1. Proposições e Conectivos

Uma proposição é algo verdadeiro ou falso.

  • ¬ (não)
  • ∧ (e) — conjunção
  • ∨ (ou) — disjunção
  • → (implica) — implicação
  • ↔ (se e somente se) — bicondicional

A Tabela que Mais Derruba Gente — Implicação

p → q só é falsa quando p é V e q é F:

pqp → q
VVV
VFF
FVV
FFV
  • Contrapositiva: p → q ≡ ¬q → ¬p (equivalentes)
  • Recíproca: q → p não é equivalente
  • De Morgan: ¬(p ∧ q) ≡ ¬p ∨ ¬q · ¬(p ∨ q) ≡ ¬p ∧ ¬q

2. Quantificadores

  • ∀ (para todo) — universal
  • ∃ (existe) — existencial

Negar troca um pelo outro:

  • ¬(∀x, P(x)) ≡ ∃x, ¬P(x)
  • ¬(∃x, P(x)) ≡ ∀x, ¬P(x)

💡 "Nem todo teste passou" = "existe teste que falhou".

3. Técnicas de Prova

Direta

Assuma a hipótese, deduza a tese.

Exemplo: soma de dois pares é par: 2a + 2b = 2(a + b).

Contraposição

Prove ¬q → ¬p.

Exemplo: se n² é par, n é par — prova-se "se n é ímpar, n² é ímpar": (2k+1)² = 2(2k²+2k)+1.

Contradição

Assuma que a tese é falsa e derive um absurdo.

Exemplo clássico: √2 é irracional.

4. Indução — A Técnica Número 1

Para provar P(n) para todo n ≥ n₀:

  1. Base: prove P(n₀)
  2. Passo: assuma P(k) (hipótese de indução) e prove P(k+1)

Prova Trabalhada — A Soma de Gauss

Afirmação: 1 + 2 + ... + n = n(n+1)/2

  • Base (n=1): 1 = 1·2/2 ✓
  • Passo: suponha válida para k. Então 1 + ... + k + (k+1) = k(k+1)/2 + (k+1) = (k+1)(k+2)/2 ✓

Indução Encontra Código

Recursão correta = indução executável:

  • Caso base ⇔ Base
  • Chamada menor ⇔ Hipótese

📝 Exercícios — 25 questões

1. Negue com De Morgan: "o deploy passou E os testes passaram".
✅ Correta! Deploy falhou OU testes falharam.
2. "Se chove, o chão molha." O chão está molhado. Choveu? Que erro lógico seria afirmar que sim?
✅ Correta! Não necessariamente — afirmar o consequente (a recíproca não vale).
3. Prove por indução: 1 + 3 + 5 + ... + (2n−1) = n².
✅ Correta! Base 1=1²; passo: n² + (2n+1) = (n+1)². ✓
4. Prove por indução: 2ⁿ > n para todo n ≥ 1.
✅ Correta! Base 2>1; passo: 2^(k+1) = 2·2^k > 2k ≥ k+1 (k ≥ 1). ✓
5. Prove diretamente: o produto de dois ímpares é ímpar.
✅ Correta! (2a+1)(2b+1) = 2(2ab+a+b)+1. ✓
6. O que é uma tautologia?
✅ Correta! Fórmula lógica que é verdadeira para todas as atribuições de valores às proposições.
7. O que é uma contradição?
✅ Correta! Fórmula lógica que é falsa para todas as atribuições de valores.
8. Qual a negação de ∀x, (x > 0 → x² > 0)?
✅ Correta! ∃x, (x > 0 ∧ x² ≤ 0)
9. O que é indução forte?
✅ Correta! Assume que P(1), P(2), ..., P(k) são verdadeiras para provar P(k+1).
10. O que significa p → q?
✅ Correta! p implica q (se p é verdadeiro, então q é verdadeiro).
11. Qual a contrapositiva de p → q?
✅ Correta! ¬q → ¬p
12. Qual a recíproca de p → q?
✅ Correta! q → p (não é equivalente à original).
13. O que é prova por contradição?
✅ Correta! Assume-se que a tese é falsa e deriva-se uma contradição.
14. O que é prova por contraposição?
✅ Correta! Prova-se ¬q → ¬p em vez de p → q.
15. Qual a negação de p ∧ q?
✅ Correta! ¬p ∨ ¬q (Lei de De Morgan).
16. Qual a negação de p ∨ q?
✅ Correta! ¬p ∧ ¬q (Lei de De Morgan).
17. O que é um invariante em programação?
✅ Correta! Uma condição que se mantém verdadeira durante a execução de um programa (ex: em loops).
18. Prove que n² + n é sempre par para qualquer inteiro n.
✅ Correta! n² + n = n(n+1). Produto de dois números consecutivos é sempre par.
19. O que é prova por exaustão?
✅ Correta! Verificar todos os casos possíveis (útil para conjuntos finitos pequenos).
20. Qual a diferença entre indução e dedução?
✅ Correta! Dedução vai do geral para o particular; indução vai do particular para o geral.
21. O que é ∀x ∈ A, P(x)?
✅ Correta! "Para todo x pertencente a A, P(x) é verdadeiro."
22. O que é ∃x ∈ A, P(x)?
✅ Correta! "Existe um x pertencente a A tal que P(x) é verdadeiro."
23. Prove por indução que 1² + 2² + ... + n² = n(n+1)(2n+1)/6.
✅ Correta! Base n=1: 1 = 1·2·3/6. Passo: some (k+1)² aos dois lados e simplifique.
24. O que é lógica de predicados?
✅ Correta! Extensão da lógica proposicional que inclui quantificadores (∀, ∃) e predicados sobre objetos.
25. Qual a negação de ∀x, ∃y, P(x,y)?
✅ Correta! ∃x, ∀y, ¬P(x,y)
