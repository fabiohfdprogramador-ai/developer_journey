🏗️ Structs, Memória Dinâmica e Compilação

Modelar dados com struct, dominar malloc/free (stack × heap) e entender o pipeline de compilação com Makefile.

1. Structs

typedef struct {
    char nome[32];
    int idade;
    double saldo;
} Conta;

Conta c = { "Ana", 30, 1500.0 };
c.saldo += 100;

void deposita(Conta *ct, double v) {  /* structs grandes: por ponteiro */
    ct->saldo += v;   /* -> é (*ct).saldo */
}
  • typedef cria um alias para o tipo
  • → (seta) acessa membros via ponteiro
  • . (ponto) acessa membros diretamente

#include <stdlib.h>

int *v = malloc(n * sizeof *v);  /* n ints no heap */
if (!v) { perror("malloc"); return 1; }

for (int i = 0; i < n; i++) v[i] = i * i;

free(v);   /* SEMPRE. v agora é inválido */
v = NULL;  /* higiene contra uso pós-free */

⚠️ Regras:

  • Todo malloc tem exatamente um free
  • Usar após free = comportamento indefinido
  • Perder o ponteiro sem free = vazamento de memória

Valgrind — O Juiz

valgrind --leak-check=full ./programa

Aponta vazamentos e acessos inválidos com linha e tudo.

3. Do .c ao Executável

gcc -o app main.c util.c esconde 4 fases:

Pré-processador

Expande #include/#define

Compilador

C → Assembly

Assembler

Assembly → Objeto .o

Linker

Juntar .o → Executável

💡 "undefined reference" é erro de link, não de compilação.

4. Makefile Mínimo que Escala

CC = gcc
CFLAGS = -Wall -Wextra -g

app: main.o util.o
    $(CC) $(CFLAGS) -o app main.o util.o

%.o: %.c util.h
    $(CC) $(CFLAGS) -c $<

clean:
    rm -f app *.o

make recompila só o que mudou (compara datas).

-g embute símbolos para o gdb:

gdb ./app
break main
run
next
print var

📝 Exercícios — 25 questões

1. Modele typedef struct { double x, y; } Ponto; e escreva double dist(Ponto a, Ponto b).
✅ Correta! sqrt((a.x-b.x)*(a.x-b.x) + (a.y-b.y)*(a.y-b.y)) (linke com -lm)
2. Aloque um array de 1000 doubles no heap, preencha com 0.5 e libere. Onde entra a checagem de erro?
✅ Correta! double *v = malloc(1000 * sizeof *v); — cheque if (!v) antes de usar; free(v) ao fim.
3. Cite dois bugs que o Valgrind pega e um que o compilador pega.
✅ Correta! Valgrind: vazamento, uso após free / fora dos limites no heap; compilador: variável não usada, tipos incompatíveis (com -Wall).
4. No Makefile acima, o que acontece ao tocar só o util.c? E só o util.h?
✅ Correta! Só util.o e o link refazem; tocar util.h refaz todos os .o que dependem dele.
5. "undefined reference to 'soma'": em que fase quebrou e quais as causas prováveis?
✅ Correta! Link: faltou compilar/linkar o .c que define soma, ou o nome difere do protótipo.
6. O que é memory leak (vazamento de memória)?
✅ Correta! Quando a memória alocada no heap não é liberada, mesmo após não ser mais necessária.
7. O que faz realloc?
✅ Correta! Redimensiona um bloco de memória previamente alocado.
8. Qual a diferença entre calloc e malloc?
✅ Correta! calloc inicializa a memória com zeros; malloc não.
9. O que é dangling pointer?
✅ Correta! Ponteiro que aponta para memória já liberada (após free).
10. O que o linker faz?
✅ Correta! Junta os arquivos objeto (.o) e bibliotecas para criar o executável final.
11. Qual a saída do comando make clean no Makefile exemplo?
✅ Correta! Remove app e todos os arquivos .o.
12. Como acessar um membro de struct via ponteiro?
✅ Correta! Usando -> (seta): ptr->membro.
13. O que é alinhamento de memória (memory alignment)?
✅ Correta! Organização dos dados na memória para otimizar acesso da CPU. Structs podem ter padding entre campos.
14. O que é padding em structs?
✅ Correta! Espaços vazios inseridos pelo compilador entre membros da struct para alinhamento.
15. O que faz a flag -g no gcc?
✅ Correta! Inclui informações de depuração no executável (para usar com gdb).
16. Como compilar múltiplos arquivos .c com gcc?
✅ Correta! gcc -o programa arquivo1.c arquivo2.c
17. O que é uma biblioteca estática?
✅ Correta! Código compilado que é incorporado ao executável no momento da linkagem (.a).
18. O que é uma biblioteca dinâmica?
✅ Correta! Código compilado carregado em tempo de execução (.so no Linux, .dll no Windows).
19. Como usar o gdb para debugar?
✅ Correta! Compile com -g, execute gdb ./programa, use break, run, next, print.
20. O que o pré-processador faz?
✅ Correta! Processa diretivas como #include, #define, #ifdef antes da compilação.
21. Qual a diferença entre #include "arquivo.h" e #include <arquivo.h>?
✅ Correta! " " busca no diretório atual; < > busca em diretórios do sistema.
22. O que é typedef?
✅ Correta! Cria um alias (apelido) para um tipo de dado existente.
23. Como alocar memória para uma struct no heap?
✅ Correta! MinhaStruct *p = malloc(sizeof(MinhaStruct));
24. O que acontece se você fizer free(p) e depois p->membro?
✅ Correta! Comportamento indefinido (uso após free).
25. Qual a sintaxe para declarar uma union em C?
✅ Correta! union { int i; float f; } u; — todos os membros compartilham o mesmo espaço de memória.
