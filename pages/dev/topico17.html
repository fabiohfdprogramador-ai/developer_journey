2. Redis na Prática

SET sessao:abc '{{...}}' EX 3600   /* TTL! */
INCR contador
EXPIRE chave 60
GET chave
DEL chave
  • Cache-aside: leia do cache, se miss → busque no banco e popule
  • TTL (Time To Live): expiração automática
  • Pub/Sub: mensageria leve
  • Estruturas: strings, lists, sets, sorted sets, hashes

3. Regra de Ouro

💡 Comece no Postgres (ele aguenta mais do que dizem — inclusive JSONB para o "documento" ocasional).

Adote um NoSQL quando um problema medido apontar a família certa.

Séries Temporais

Telemetria, métricas: o padrão colunar comprime 10-100× e agrega absurdamente rápido.

📝 Exercícios — 25 questões

1. Sessões de usuário com expiração automática: qual banco e qual comando-chave?
✅ Correta! Redis, SET ... EX (TTL nativo).
2. Dashboard que agrega bilhões de leituras de sensores por hora: família e porquê?
✅ Correta! Colunar (ClickHouse): compressão + agregação por coluna.
3. Seu catálogo tem atributos que variam por tipo de produto. Duas soluções razoáveis?
✅ Correta! Postgres com JSONB numa coluna de atributos; ou documento se TODO o acesso for por documento.
4. Por que "usar MongoDB porque JSON é mais fácil" costuma cobrar caro depois?
✅ Correta! Sem esquema e sem joins fortes, a consistência migra para a aplicação — e integridade "de código" fura sob concorrência.
5. Qual a diferença entre chave-valor e documento?
✅ Correta! Chave-valor: valor é opaco (string/binário); Documento: valor tem estrutura (JSON).
6. O que é Redis? Para que serve?
✅ Correta! Banco de dados chave-valor em memória, usado para cache, sessões, filas, rate limiting.
7. O que é MongoDB? Para que serve?
✅ Correta! Banco de dados orientado a documentos (JSON), usado para esquemas flexíveis e protótipos.
8. O que é ClickHouse? Para que serve?
✅ Correta! Banco de dados colunar, usado para analytics e séries temporais.
9. O que é Neo4j? Para que serve?
✅ Correta! Banco de dados de grafos, usado para relacionamentos complexos (ex: redes sociais, fraudes).
10. O que é TTL no Redis?
✅ Correta! Time To Live: tempo de vida de uma chave, após o qual ela é automaticamente removida.
11. O que é cache-aside?
✅ Correta! Padrão onde a aplicação consulta o cache primeiro; se miss, busca no banco e popula o cache.
12. Qual a diferença entre banco relacional e NoSQL?
✅ Correta! Relacional: tabelas com esquema fixo, SQL, ACID; NoSQL: diversos modelos (chave-valor, documento, colunar, grafo), eventual consistency.
13. O que é eventual consistency?
✅ Correta! Garantia que o sistema se tornará consistente eventualmente, mas não imediatamente.
14. O que é strong consistency?
✅ Correta! Garantia que todos os leituras veem a versão mais recente dos dados.
15. O que é JSONB no PostgreSQL?
✅ Correta! Tipo de dado que armazena JSON em formato binário, permitindo consultas e índices.
16. Qual banco NoSQL é melhor para cache?
✅ Correta! Redis (chave-valor em memória).
17. Qual banco NoSQL é melhor para analytics?
✅ Correta! ClickHouse (colunar).
18. Qual banco NoSQL é melhor para grafos?
✅ Correta! Neo4j.
19. Qual banco NoSQL é melhor para documentos flexíveis?
✅ Correta! MongoDB.
20. O que é Pub/Sub no Redis?
✅ Correta! Padrão de mensageria onde publicadores enviam mensagens para canais e assinantes as recebem.
21. O que é sharding em bancos NoSQL?
✅ Correta! Particionamento horizontal de dados entre múltiplos nós.
22. O que é replicação em bancos NoSQL?
✅ Correta! Cópia dos dados em múltiplos nós para redundância e disponibilidade.
23. O que é CAP Theorem?
✅ Correta! Teorema que afirma que um sistema distribuído não pode garantir simultaneamente: Consistência, Disponibilidade e Tolerância a Partições.
24. Qual a diferença entre SQL e NoSQL em termos de esquema?
✅ Correta! SQL: esquema fixo (tabelas); NoSQL: esquema flexível (schema-less).
25. Qual banco é recomendado para séries temporais e por quê?
✅ Correta! ClickHouse (colunar): compressão eficiente, agregações rápidas por coluna.
