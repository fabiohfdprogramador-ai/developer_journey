💻 Arquitetura — Como Seu Código Executa

Bits, a hierarquia de memória e o caminho do C até a CPU — o capítulo que explica por que dois códigos "iguais" têm velocidades 10× diferentes.

1. Representação: Tudo é Bit

Inteiros

  • Sem sinal: base 2
  • Com sinal: complemento de dois (o bit mais alto vale -2ⁿ⁻¹)
  • Int de 32 bits vai de -2³¹ a 2³¹-1
  • Somar 1 ao máximo dá o mínimo (overflow silencioso)

Hexadecimal

Atalho de leitura: 1 dígito hex = 4 bits (0xFF = 255)

Ponto Flutuante (IEEE 754)

  • Sinal + expoente + mantissa
  • 0.1 + 0.2 != 0.3
  • ⚠️ Nunca compare floats com ==
  • ⚠️ Nunca guarde dinheiro em float (use inteiros de centavos)

2. A CPU em Uma Página

Ciclo: buscar instrução → decodificar → executar — bilhões de vezes por segundo.

  • Pipeline: várias instruções em estágios simultâneos
  • Branch predictor: previsão de desvio
  • Registradores: a memória mais rápida que existe
  • ISA (x86-64, ARM): contrato entre compilador e processador

gcc -S arquivo.c mostra o assembly do seu C — leia uma vez na vida.

3. A Hierarquia de Memória

NívelTamanho típicoLatência (ordem)
Registradoresbytes~0,3 ns
Cache L1 / L2 / L3KB → MB1 → 10 ns
RAMGBs~100 ns
SSDTBs~100 μs
Rede (mesmo DC)—~500 μs

Cada nível é ~10-100× mais lento que o anterior.

  • CPU carrega memória em linhas de cache (64 bytes)
  • Acessar dados contíguos e em sequência aproveita a linha inteira
  • Pular aleatoriamente paga RAM toda vez

📝 Exercícios — 25 questões

1. Converta 0xC3 para decimal e binário.
✅ Correta! 195; 1100 0011
2. Por que int x = 2147483647; x = x + 1; resulta em -2147483648?
✅ Correta! Complemento de dois: estourou para o menor valor (overflow).
3. Por que comparar double com == é bug em potencial? Qual a alternativa?
✅ Correta! Erros de arredondamento binário; compare fabs(a-b) < eps.
4. Ordene por latência: RAM, L1, SSD, registrador, rede local.
✅ Correta! registrador < L1 < RAM < SSD < rede
5. Explique com linhas de cache por que iterar um array de structs pequenos é mais rápido que seguir uma lista ligada.
✅ Correta! Structs contíguos: uma linha de 64 B traz vários elementos; nós da lista estão espalhados → um cache miss por nó.
6. O que é pipeline em uma CPU?
✅ Correta! Técnica que executa várias instruções em estágios simultâneos para aumentar throughput.
7. O que é cache miss?
✅ Correta! Quando os dados solicitados não estão no cache, forçando acesso à memória principal.
8. O que é cache hit?
✅ Correta! Quando os dados solicitados estão no cache.
9. Qual a diferença entre RAM e ROM?
✅ Correta! RAM é volátil e pode ser escrita; ROM é não-volátil e geralmente somente leitura.
10. O que é endianness?
✅ Correta! Ordem dos bytes na memória: little-endian (byte menos significativo primeiro) ou big-endian.
11. Qual a diferença entre SRAM e DRAM?
✅ Correta! SRAM é mais rápida e cara (usada em cache); DRAM é mais lenta e barata (usada em RAM principal).
12. O que é ponto flutuante IEEE 754?
✅ Correta! Padrão para representar números reais em binário: sinal + expoente + mantissa.
13. O que é localidade espacial?
✅ Correta! Tendência de acessar endereços de memória próximos uns dos outros.
14. O que é localidade temporal?
✅ Correta! Tendência de acessar o mesmo endereço de memória repetidamente.
15. Qual a largura típica de uma linha de cache?
✅ Correta! 64 bytes.
16. O que é ALU (Arithmetic Logic Unit)?
✅ Correta! Componente da CPU que executa operações aritméticas e lógicas.
17. O que é barramento (bus)?
✅ Correta! Caminho de comunicação entre componentes do computador (dados, endereço, controle).
18. O que é frequência de clock?
✅ Correta! Número de ciclos por segundo (medido em Hz) que a CPU executa.
19. O que é código de máquina?
✅ Correta! Instruções binárias que a CPU executa diretamente.
20. O que é assembly?
✅ Correta! Representação textual do código de máquina, com mnemônicos para instruções.
21. Qual a diferença entre RISC e CISC?
✅ Correta! RISC: instruções reduzidas e simples; CISC: instruções complexas e variadas.
22. O que é overflow em aritmética de inteiros?
✅ Correta! Quando o resultado de uma operação excede a capacidade do tipo.
23. O que é underflow em ponto flutuante?
✅ Correta! Quando o resultado é tão pequeno que não pode ser representado (vira 0).
24. O que faz o compilador?
✅ Correta! Traduz código de alto nível (C, Go) para código de máquina ou assembly.
25. O que é JIT (Just-In-Time) compilation?
✅ Correta! Compilação em tempo de execução (usada em VMs como JVM, V8).
