⚙️ C: Fundamentos e Controle de Fluxo

Compilar e rodar seu primeiro programa, dominar tipos, operadores e controle de fluxo — C é pequena, rápida e não esconde nada.

1. O Primeiro Programa

#include <stdio.h>   /* traz printf, scanf... */

int main(void) {
    printf("Hello, world!\n");
    return 0;          /* 0 = sucesso para o SO */
}
gcc -Wall -Wextra -o hello hello.c && ./hello

-Wall -Wextra liga os avisos — sempre. Aviso de compilador é professor grátis.

3. Operadores e Controle

Aritméticos: + - * / % · Comparação: == != < > <= >= · Lógicos: && || !

if / else

if (nota >= 90) printf("A\n");
else if (nota >= 70) printf("B\n");
else printf("reprovado\n");

for

for (int i = 0; i < 5; i++) printf("%d ", i);  /* 0 1 2 3 4 */

while

int n = 5, fat = 1;
while (n > 1) { fat *= n; n--; }  /* fat == 120 */

switch

switch (op) {
    case '+': r = a + b; break;
    case '-': r = a - b; break;
    default: printf("op inválida\n");
}

⚠️ As Três Pegadinhas Clássicas

  • = (atribui) dentro de if no lugar de == (compara)
  • Esquecer break no switch
  • scanf("%d", &x) exige o & (endereço)

4. Operadores Bit a Bit

Operam nos bits individuais dos números — úteis para flags, compactação e performance.

OperadorExemploResultado
& (AND)5 & 31 (0101 & 0011 = 0001)
| (OR)5 | 37 (0101 | 0011 = 0111)
^ (XOR)5 ^ 36 (0101 ^ 0011 = 0110)
~ (NOT)~5-6 (inverte todos os bits)
<< (shift esq)5 << 110 (dobra)
>> (shift dir)5 >> 12 (divide por 2)
// Exemplo prático: flags
#define READ   (1 << 0)  // 0001
#define WRITE  (1 << 1)  // 0010
#define EXEC   (1 << 2)  // 0100

int permissao = READ | WRITE;  // 0011
if (permissao & READ) printf("Pode ler\n");

📝 Exercícios — 25 questões

1. Escreva um programa que lê um inteiro e diz se é par ou ímpar.
✅ Correta! if (n % 2 == 0) printf("par\n"); else printf("ímpar\n");
2. Imprima a tabuada do 7 com um for.
✅ Correta! for (int i = 1; i <= 10; i++) printf("7x%d=%d\n", i, 7*i);
3. FizzBuzz de 1 a 30: múltiplo de 3 → "Fizz", de 5 → "Buzz", de ambos → "FizzBuzz".
✅ Correta! Teste % 15 primeiro (ou combine condições).
4. Em C, quanto vale 9 / 2 e 9 % 2? E 9.0 / 2?
✅ Correta! 4; 1; 4.5
5. Leia notas até o usuário digitar -1 e imprima a média (while).
✅ Correta! Acumule soma e qtd no while; média = (double)soma/qtd — o cast evita divisão inteira.
6. Qual o tipo correto para armazenar o caractere 'A'?
✅ Correta! char
7. O que significa int x = 5 << 2;?
✅ Correta! x = 20 (5 × 2² = 20)
8. O que faz o operador % em C?
✅ Correta! Resto da divisão (módulo).
9. Como declarar uma variável bool em C?
✅ Correta! #include <stdbool.h> e bool flag = true;
10. Qual o tamanho de um int na maioria das arquiteturas modernas?
✅ Correta! 4 bytes (32 bits)
11. O que é && em C?
✅ Correta! Operador lógico AND ("E").
12. Como compilar um programa C com avisos ativados?
✅ Correta! gcc -Wall -Wextra -o programa programa.c
13. Qual a saída de printf("%d", 10 & 6);?
✅ Correta! 2 (1010 & 0110 = 0010)
14. Qual a saída de printf("%d", 10 | 6);?
✅ Correta! 14 (1010 | 0110 = 1110)
15. O que é um if aninhado?
✅ Correta! Um if dentro de outro if.
16. Como fazer um loop infinito em C?
✅ Correta! while(1) { } ou for(;;) { }
17. Qual o erro comum com scanf?
✅ Correta! Esquecer o & antes da variável: scanf("%d", &x);
18. O que faz break dentro de um switch?
✅ Correta! Sai do switch, evitando "cair" no próximo caso.
19. O que acontece se esquecer o break no switch?
✅ Correta! O programa "cai" para o próximo case e o executa também.
20. Como imprimir o valor de uma variável double?
✅ Correta! printf("%f", x);
21. O que é o #include <stdio.h>?
✅ Correta! Inclui a biblioteca padrão de entrada e saída (printf, scanf, etc).
22. Qual a diferença entre = e == em C?
✅ Correta! = é atribuição; == é comparação.
23. Como declarar uma constante em C?
✅ Correta! const int MAX = 100;
24. O que retorna main()?
✅ Correta! Um inteiro (0 geralmente indica sucesso, diferente de 0 indica erro).
25. Como ler um inteiro do usuário?
✅ Correta! scanf("%d", &variavel);
