🔄 Algoritmos Clássicos

Busca binária, os sorts que importam, BFS/DFS em grafos e a ideia de programação dinâmica — o kit que resolve entrevistas e problemas reais.

1. Busca Binária

int busca_binaria(int *v, int n, int alvo) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int meio = lo + (hi - lo) / 2;  /* evita overflow de (lo+hi) */
        if (v[meio] == alvo) return meio;
        if (v[meio] < alvo) lo = meio + 1;
        else hi = meio - 1;
    }
    return -1;
}
  • Pré-condição: array ordenado
  • Invariante: o alvo, se existe, está em [lo, hi]

Merge Sort (Divisão e Conquista)

void merge_sort(int *v, int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    merge_sort(v, l, m);
    merge_sort(v, m + 1, r);
    merge(v, l, m, r);  /* intercala os dois arrays ordenados */
}

3. Grafos: BFS e DFS

BFS (Busca em Largura)

BFS(origem):
    fila = [origem]
    visitado[origem] = true
    enquanto fila não vazia:
        v = fila.pop_front()
        para cada vizinho u de v:
            se não visitado[u]:
                visitado[u] = true
                fila.push_back(u)
  • Explora em ondas — usa FILA
  • Dá o menor caminho em arestas (grafos sem peso)

DFS (Busca em Profundidade)

DFS(v):
    visitado[v] = true
    para cada vizinho u de v:
        se não visitado[u]:
            DFS(u)
  • Mergulha fundo — usa PILHA/recursão
  • Detecta ciclos e produz ordenação topológica

4. Programação Dinâmica

Quando a recursão repete subproblemas, guarde os resultados (memorização) ou construa de baixo para cima:

long fib(int n) {  /* O(n) em vez de exponencial */
    long a = 0, b = 1;
    for (int i = 0; i < n; i++) {
        long t = a + b;
        a = b;
        b = t;
    }
    return a;
}

Receita DP

  1. Defina o subproblema
  2. Escreva a recorrência
  3. Resolva na ordem certa guardando respostas

5. Exemplo Resolvido — Troco com DP

Moedas {1, 3, 4}, alvo 6.

dp[x] = mínimo de moedas para x; dp[0] = 0; dp[x] = 1 + min(dp[x−moeda])

dp: 0,1,2,1,1,2,2 → resposta 2 (3+3)

Complexidade: O(alvo × moedas).

📝 Exercícios — 25 questões

1. Trace a busca binária de 31 em [2, 5, 8, 12, 19, 23, 31, 44]: quais índices meio são visitados?
✅ Correta! meio=3 (12) → 5 (23) → 6 (31): 3 passos.
2. Por que merge sort é O(n log n)?
✅ Correta! log n níveis de divisão × O(n) de intercalação por nível.
3. Modele: dado o grafo de dependências de microsserviços, como achar a ordem segura de deploy? Que algoritmo?
✅ Correta! Ordenação topológica via DFS (o grafo precisa ser acíclico).
4. BFS a partir de A em: A-B, A-C, B-D, C-D, D-E. Distância de A a E?
✅ Correta! A(0) → B,C(1) → D(2) → E(3). Distância = 3.
5. Escreva a recorrência DP do troco mínimo e calcule para moedas {1, 5, 10} e alvo 12.
✅ Correta! dp[x] = 1 + min(dp[x-1], dp[x-5], dp[x-10]); dp[12] = 3 (10+1+1).
6. Qual a diferença entre BFS e DFS?
✅ Correta! BFS explora em largura (usa fila); DFS explora em profundidade (usa pilha/recursão).
7. Qual a complexidade de tempo do BFS em um grafo com V vértices e E arestas?
✅ Correta! O(V + E)
8. Qual a complexidade de tempo do DFS em um grafo com V vértices e E arestas?
✅ Correta! O(V + E)
9. O que é ordenação topológica?
✅ Correta! Ordenação de vértices em um DAG onde para toda aresta u→v, u aparece antes de v.
10. Qual algoritmo é usado para encontrar o menor caminho em grafos com pesos positivos?
✅ Correta! Dijkstra (BFS + heap de prioridade).
11. Qual algoritmo é usado para encontrar o menor caminho em grafos com pesos negativos?
✅ Correta! Bellman-Ford (O(VE)).
12. O que é programação dinâmica?
✅ Correta! Técnica que resolve problemas complexos quebrando em subproblemas e guardando resultados para evitar recálculo.
13. Qual a diferença entre memoization e tabulation?
✅ Correta! Memoization: top-down (recursivo com cache); Tabulation: bottom-up (iterativo com tabela).
14. Qual a complexidade do algoritmo de Dijkstra com heap?
✅ Correta! O((V + E) log V)
15. O que é backtracking?
✅ Correta! Técnica de busca que tenta todas as possibilidades e retrocede quando falha.
16. Qual a complexidade do insertion sort no pior caso?
✅ Correta! O(n²)
17. Qual a complexidade do insertion sort no melhor caso?
✅ Correta! O(n) (array já ordenado)
18. Qual a complexidade do quick sort no melhor caso?
✅ Correta! O(n log n)
19. Qual a complexidade do quick sort no pior caso?
✅ Correta! O(n²)
20. Qual algoritmo de ordenação é estável?
✅ Correta! Merge sort (e insertion sort) — mantém a ordem relativa de elementos iguais.
21. O que é DAG (Directed Acyclic Graph)?
✅ Correta! Grafo direcionado sem ciclos.
22. Qual algoritmo detecta ciclos em um grafo direcionado?
✅ Correta! DFS com três estados (não visitado, visitando, visitado).
23. Qual a complexidade do heapsort?
✅ Correta! O(n log n) em todos os casos
24. O que é o problema do caixeiro viajante (TSP)?
✅ Correta! Encontrar o menor caminho que visita todas as cidades uma vez e retorna à origem. É NP-difícil.
25. Qual a diferença entre P e NP?
✅ Correta! P: problemas resolvíveis em tempo polinomial; NP: problemas verificáveis em tempo polinomial.
