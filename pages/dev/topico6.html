📍 Ponteiros — O Coração do C (e da Máquina)

O capítulo mais importante do livro. Entender endereços, & e *, aritmética de ponteiros e a verdade sobre arrays.

1. O Modelo Mental

Toda variável mora num endereço de memória. Um ponteiro é uma variável que guarda um endereço.

int x = 42;
int *p = &x;      /* & = "endereço de"; p aponta para x */
printf("%d\n", *p); /* * = "valor apontado": 42 */
*p = 100;          /* escreve NO ENDEREÇO apontado */
printf("%d\n", x); /* 100 - x mudou através de p */
    Variável x (valor 42)    →    Ponteiro p (endereço de x)
    ┌─────────┐                    ┌─────────┐
    │   x=42   │  ←─────────────   │ p=&x   │
    └─────────┘                    └─────────┘
    Endereço: 0x7fff...            Endereço: 0x7fff...

Regras de ouro:

  • NULL = "não aponta para nada" (sempre inicialize)
  • Desreferenciar NULL = crash
  • Leia declarações de trás para frente: int *p = "p é ponteiro para int"

2. O Mistério do Capítulo 4, Resolvido

void dobra(int *x) {
    *x = *x * 2;   /* recebe o ENDEREÇO */
}

int n = 10;
dobra(&n);
printf("%d\n", n); /* 20 - agora sim */

"Passagem por referência" em C é isto: passar o endereço por valor.

💡 É também por que scanf exige &x.

3. Ponteiros e Arrays — A Verdade

O nome de um array decai para o endereço do primeiro elemento. A aritmética de ponteiros anda em unidades do tipo:

int v[4] = {10, 20, 30, 40};
int *p = v;          /* == &v[0] */
printf("%d\n", *(p + 2)); /* 30 - pulou 2 ints, não 2 bytes */
/* v[i] é literalmente *(v + i) */

Por isso arrays chegam "por referência" em funções: o que viaja é o endereço.

4. Exemplo Resolvido — Swap, o Rito de Passagem

void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int x = 1, y = 2;
swap(&x, &y);
/* x==2, y==1 */

Se você explica por que o swap sem ponteiros não funciona, os ponteiros são seus.

5. Ponteiros para Ponteiros

int x = 5;
int *p = &x;
int **pp = &p;

printf("%d\n", **pp);  /* 5 */
printf("%p\n", *pp);   /* endereço de x */
printf("%p\n", pp);    /* endereço de p */
    x=5    ←    p=&x    ←    pp=&p
    ┌───┐      ┌────┐      ┌─────┐
    │ 5 │  ←─  │ &x │  ←─  │ &p  │
    └───┘      └────┘      └─────┘

6. ⚠️ Os Três Crimes de Ponteiro

  • 1. Usar ponteiro não inicializado (aponta para lixo)
  • 2. Desreferenciar NULL
  • 3. Retornar endereço de variável local (dangling pointer)

Ferramentas: gdb e Valgrind caçam os três.

📝 Exercícios — 25 questões

1. Desenhe (papel!) a memória de: int a=5; int *p=&a; int **pp=&p;. Quanto vale **pp?
✅ Correta! 5 (pp → p → a)
2. Escreva void troca_sinais(int *v, int n) que inverte o sinal de cada elemento.
✅ Correta! for (int i = 0; i < n; i++) v[i] = -v[i];
3. Por que strlen recebe const char *s e funciona para qualquer string?
✅ Correta! Recebe o endereço do 1º char e anda até o terminador; const promete não alterar.
4. Implemente size_t meu_strlen(const char *s) com um ponteiro andando até o \0.
✅ Correta! const char *q = s; while (*q) q++; return q - s;
5. O que está errado: int *f(void){ int x=7; return &x; }?
✅ Correta! Retorna endereço de variável local destruída — comportamento indefinido.
6. O que é um dangling pointer?
✅ Correta! Ponteiro que aponta para uma região de memória já liberada ou fora de escopo.
7. Qual a diferença entre int *p e int p?
✅ Correta! int *p é um ponteiro para inteiro; int p é um inteiro.
8. O que significa int *p = NULL;?
✅ Correta! Ponteiro p não aponta para lugar nenhum.
9. O que acontece se desreferenciarmos NULL?
✅ Correta! O programa crasha com segmentation fault.
10. Como acessar o valor apontado por um ponteiro?
✅ Correta! Usando o operador * (asterisco): *p.
11. O que é aritmética de ponteiros?
✅ Correta! Operações como p++ que avançam o ponteiro em unidades do tamanho do tipo apontado.
12. Se int v[5], qual a relação entre v e &v[0]?
✅ Correta! São equivalentes: ambos apontam para o primeiro elemento do array.
13. Como passar um array para uma função que o modifica?
✅ Correta! Passando o ponteiro para o primeiro elemento: funcao(v) ou funcao(&v[0]).
14. O que é sizeof(void *)?
✅ Correta! Tamanho de um ponteiro (geralmente 8 bytes em 64-bit, 4 bytes em 32-bit).
15. Para que serve const com ponteiros?
✅ Correta! Indica que o valor apontado não será modificado (const int *p) ou que o ponteiro é constante (int *const p).
16. Qual a diferença entre int *p e int p[] em parâmetros de função?
✅ Correta! São idênticos: o array decai para ponteiro. int p[] é sintaxe açucarada para int *p.
17. O que acontece no código: int *p; *p = 5;?
✅ Correta! Comportamento indefinido (p não foi inicializado, aponta para lixo).
18. Como criar um ponteiro para uma função em C?
✅ Correta! int (*funcPtr)(int, int); — ponteiro para função que recebe dois ints e retorna int.
19. O que é void * em C?
✅ Correta! Ponteiro genérico que pode apontar para qualquer tipo (usado em malloc).
20. Como acessar um elemento de array usando aritmética de ponteiros?
✅ Correta! *(v + i) é equivalente a v[i].
21. O que é pointer aliasing?
✅ Correta! Quando dois ponteiros apontam para o mesmo endereço de memória.
22. Como copiar o valor apontado para outro ponteiro?
✅ Correta! int y = *p; ou int *q = malloc(sizeof(int)); *q = *p;
23. O que é Ponteiro Inteligente (smart pointer)?
✅ Correta! Abstração em C++/Rust que gerencia automaticamente a vida útil da memória apontada. C não tem nativamente.
24. Qual o valor de *p após int x=10; int *p=&x; *p=20;?
✅ Correta! 20 — modificou o valor de x através do ponteiro.
25. Qual a saída de printf("%p", p);?
✅ Correta! Imprime o endereço de memória armazenado no ponteiro p (em hexadecimal).
