📊 Arrays e Strings

Vetores e matrizes, o modelo de string do C (bytes terminados em '\0') e as funções de string.h — mais o primeiro encontro honesto com a memória contígua.

1. Arrays

int notas[5] = {90, 85, 70, 60, 95};
notas[0] = 100;  /* índices de 0 a 4 */
int n = sizeof notas / sizeof notas[0];  /* 5 elementos */

double media = 0;
for (int i = 0; i < n; i++) {
    media += notas[i];
}
media /= n;

Um array é um bloco contíguo de memória.

⚠️ C não checa limites: notas[7] compila e corrompe memória alheia — comportamento indefinido.

Matrizes

int grade[3][4];  /* 3 linhas × 4 colunas */
/* contíguas: linha após linha — isso importa para cache (cap. 13) */

2. Strings — Não Existe "Tipo String"

Uma string em C é um array de char terminado no byte 0 ('\0'):

char nome[16] = "Ana";
/* memória: 'A' 'n' 'a' '\0' ... */
printf("%s tem %zu letras\n", nome, strlen(nome));  /* 3 */

3. Exemplo Resolvido — Inverter uma String

void inverte(char *s) {
    int i = 0, j = (int)strlen(s) - 1;
    while (i < j) {
        char tmp = s[i];
        s[i] = s[j];
        s[j] = tmp;
        i++;
        j--;
    }
}

Dois índices caminhando um contra o outro — o padrão "two pointers" que você reencontrará em entrevistas.

4. ⚠️ A Causa Nº 1 de Vulnerabilidades Históricas

Escrever além do array (buffer overflow):

char buf[8];
strcpy(buf, entrada_do_usuario);
/* se entrada tem 30 bytes, sobrescreve a pilha */

Sempre limite: snprintf / strncpy + tamanho do buffer.

📝 Exercícios — 25 questões

1. Encontre o maior elemento de um int v[n].
✅ Correta! Varra guardando o máximo: int max = v[0]; for (int i=1; i<n; i++) if (v[i] > max) max = v[i];
2. Conte as vogais de uma string.
✅ Correta! Laço com switch ou strchr("aeiou", tolower(s[i])).
3. Por que if (a == b) não compara duas strings? O que usar?
✅ Correta! == compara endereços; use strcmp(a, b) == 0.
4. Implemente int eh_palindromo(char *s).
✅ Correta! Two pointers comparando em vez de trocar.
5. Some as diagonais de uma matriz 3×3.
✅ Correta! Principal: m[i][i]; Secundária: m[i][2-i].
6. O que faz strlen("Hello")?
✅ Correta! Retorna 5 (não conta o \0).
7. Como copiar uma string com segurança?
✅ Correta! strncpy(dest, src, size - 1); dest[size - 1] = '\0';
8. O que é um buffer overflow?
✅ Correta! Escrever dados além do espaço alocado para um buffer, corrompendo memória adjacente.
9. Como declarar uma string de 20 caracteres em C?
✅ Correta! char str[20]; (comporta 19 caracteres + '\0')
10. O que faz strcat(a, b)?
✅ Correta! Concatena a string b ao final de a.
11. Qual a diferença entre char s[] = "abc" e char *s = "abc"?
✅ Correta! s[] é um array modificável; *s aponta para um literal (geralmente em seção de somente leitura).
12. Como contar o número de palavras em uma string?
✅ Correta! Contar transições de não-espaço para espaço (ou vice-versa).
13. O que é uma matriz em C?
✅ Correta! Um array de arrays (bloco contíguo 2D).
14. Como acessar o terceiro elemento de um array v?
✅ Correta! v[2] (índices começam em 0).
15. O que é o terminador nulo em strings C?
✅ Correta! O caractere '\0' que marca o fim da string.
16. Como converter uma string para maiúsculas?
✅ Correta! Laço com toupper(s[i]) (inclua <ctype.h>).
17. O que faz snprintf?
✅ Correta! Formata uma string com limite de tamanho (versão segura de sprintf).
18. Como encontrar a primeira ocorrência de um caractere em uma string?
✅ Correta! strchr(s, char).
19. O que é comportamento indefinido em C?
✅ Correta! Situações onde o padrão C não especifica o que deve acontecer (ex: acessar array fora dos limites).
20. Como comparar duas strings ignorando maiúsculas/minúsculas?
✅ Correta! strcasecmp(a, b) (POSIX) ou implementar com tolower.
21. Como ler uma linha inteira (com espaços) do usuário?
✅ Correta! fgets(buffer, size, stdin).
22. O que é localidade de referência (cache locality)?
✅ Correta! Acesso a dados próximos na memória, que aproveita as linhas de cache.
23. Como inverter uma string in-place?
✅ Correta! Two pointers trocando caracteres das pontas.
24. O que faz sizeof em um array?
✅ Correta! Retorna o tamanho total em bytes do array.
25. Como remover espaços em branco no início e fim de uma string?
✅ Correta! Percorrer do início enquanto espaço, depois do fim enquanto espaço, e deslocar a string.
