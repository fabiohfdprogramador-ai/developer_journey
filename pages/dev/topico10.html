📈 Big-O — A Régua dos Algoritmos

Medir crescimento, não cronômetro: as classes O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ) — e a habilidade de olhar um código e dizer o custo.

1. A Ideia

Big-O descreve como o custo cresce com o tamanho da entrada, ignorando constantes e termos menores:

3n² + 50n + 7 é O(n²)

Vale para tempo e para espaço.

2. Lendo Código

for (i = 0; i < n; i++)         /* O(n) */
    for (j = 0; j < n; j++)       /* x O(n) = O(n²) */
        ...

while (n > 1) {
    n = n / 2;                    /* O(log n): divide */
}

Regras

  • Sequência: soma (fica o dominante)
  • Aninhamento: multiplica
  • Dividir pela metade a cada passo = O(log n)

3. Por que log n é Mágico

Busca binária em 1 bilhão de itens ordenados:

  • ⌈log₂ 10⁹⌉ = 30 comparações
  • Busca linear: até 10⁹

💡 É a diferença entre "instantâneo" e "um segundo inteiro de CPU" — e a razão de índices de banco existirem.

📝 Exercícios — 25 questões

1. Classifique: (a) somar um array; (b) verificar duplicatas com dois laços; (c) verificar duplicatas com um hash set.
✅ Correta! O(n); O(n²); O(n) médio
2. Um algoritmo O(n²) processa 1000 itens em 1 s. Estimativa para 10.000?
✅ Correta! 100× o tempo → ~100 s
3. Qual o custo de inserir no início de um array? E de uma lista ligada?
✅ Correta! Array: O(n) (empurra todo mundo); lista: O(1)
4. log₂(1024) = ? E quantos passos a busca binária faz em 10⁶ itens?
✅ Correta! 10; ~20
5. Dois laços em sequência (não aninhados) sobre n: qual o Big-O?
✅ Correta! O(n) + O(n) = O(n)
6. Qual o Big-O de um algoritmo que faz 2n² + 100n + 5 operações?
✅ Correta! O(n²) (termo dominante)
7. Qual o Big-O da busca em uma árvore binária balanceada?
✅ Correta! O(log n)
8. Qual o Big-O de um algoritmo que divide o problema pela metade a cada passo?
✅ Correta! O(log n)
9. Qual o Big-O de três laços aninhados, cada um rodando n vezes?
✅ Correta! O(n³)
10. Qual o Big-O de um algoritmo que visita cada elemento de uma matriz n×n?
✅ Correta! O(n²)
11. Qual o Big-O de um algoritmo que recursivamente chama a si mesmo duas vezes com n-1?
✅ Correta! O(2ⁿ)
12. O que significa O(1)?
✅ Correta! Tempo constante, independente do tamanho da entrada.
13. O que significa Ω (Omega) em análise de algoritmos?
✅ Correta! Limite inferior (melhor caso) do custo.
14. O que significa Θ (Theta) em análise de algoritmos?
✅ Correta! Limite justo (tanto superior quanto inferior).
15. Qual o Big-O de percorrer uma lista ligada?
✅ Correta! O(n)
16. Qual o Big-O de percorrer um array?
✅ Correta! O(n)
17. Qual o Big-O do melhor caso do quicksort?
✅ Correta! O(n log n)
18. Qual o Big-O do pior caso do quicksort?
✅ Correta! O(n²)
19. Qual o Big-O do merge sort?
✅ Correta! O(n log n) em todos os casos
20. Qual o Big-O de f(n) = 5n + 3log(n)?
✅ Correta! O(n)
21. Qual o Big-O de um algoritmo que faz n! operações?
✅ Correta! O(n!) (pior que exponencial)
22. Qual o Big-O do algoritmo de Dijkstra com heap?
✅ Correta! O((V + E) log V)
23. Qual o Big-O da busca em uma tabela hash?
✅ Correta! O(1) médio, O(n) pior caso
24. Qual o Big-O de for (i=0; i<n; i+=2)?
✅ Correta! O(n) (constante 1/2 é ignorada)
25. Qual o Big-O de for (i=0; i<n; i++) for (j=0; j<i; j++)?
✅ Correta! O(n²) (soma 1+2+...+n = n(n+1)/2)
