🐹 Go — Simplicidade que Escala

Go idiomático: tipos, structs e interfaces, o tratamento de erros e — a joia — concorrência com goroutines, channels e context. Depois de C e SO, nada aqui é mágica: você sabe o que o runtime faz por você.

1. O Básico com Sotaque Go

package main

import "fmt"

type Sensor struct {
    ID    string
    Value float64
}

func (s Sensor) Label() string {  // método (receiver por valor)
    return fmt.Sprintf("%s=%.2f", s.ID, s.Value)
}

func main() {
    s := Sensor{ID: "temp-01", Value: 23.7}  // := infere o tipo
    readings := []float64{21.2, 23.7, 25.1}   // slice (array dinâmico)
    
    total := 0.0
    for _, v := range readings {
        total += v
    }
    fmt.Println(s.Label(), "média:", total/float64(len(readings)))
}
  • Slices: estrutura do dia a dia (append cresce)
  • Maps: m := map[string]int{}
  • Sem herança: composição + interfaces

3. Erros como Valores

func LoadConfig(path string) (*Config, error) {
    b, err := os.ReadFile(path)
    if err != nil {
        return nil, fmt.Errorf("lendo config %s: %w", path, err)
    }
    // ...
}

// no chamador:
cfg, err := LoadConfig("app.yaml")
if err != nil {
    log.Fatal(err)
}
  • Sem exceções: o erro é retorno
  • Tratado onde acontece
  • Contexto empilhado via %w (inspecionado com errors.Is/As)

4. Concorrência — Goroutines e Channels

func worker(id int, jobs <-chan string, results chan<- string) {
    for url := range jobs {  // consome até fecharem o canal
        results <- fetch(url) // envia (bloqueia se cheio)
    }
}

func main() {
    jobs, results := make(chan string), make(chan string)
    
    for i := 1; i <= 5; i++ {
        go worker(i, jobs, results)  // 5 goroutines
    }
    
    go func() {
        for _, u := range urls { jobs <- u }
        close(jobs)
    }()
    
    for range urls {
        fmt.Println(<-results)
    }
}
  • Goroutine: função concorrente levíssima (KBs) — runtime multiplexa milhares em poucas threads do SO
  • Channel: comunicação + sincronização no mesmo tubo
  • Lema: "não comunique compartilhando memória; compartilhe memória comunicando."
  • select: espera múltiplos canais
  • sync.WaitGroup: espera um grupo terminar
  • context.Context: cancelamento e deadline atravessando a pilha
  • go test -race no CI, sempre

📝 Exercícios — 25 questões

1. Por que 100.000 goroutines são viáveis e 100.000 threads do SO não?
✅ Correta! Stacks de KBs crescíveis + scheduler do runtime × MBs fixos e trocas de contexto do kernel.
2. Escreva Median(xs []float64) (float64, error) retornando erro para slice vazio.
✅ Correta! Ordene cópia, trate len==0 com errors.New, média dos centrais se par.
3. Monte um pipeline: um canal de ints, 3 goroutines que elevam ao quadrado, um canal de saída.
✅ Correta! for v := range in { out <- v*v } em 3 goroutines; feche out com WaitGroup.
4. O que acontece ao enviar num canal sem ninguém lendo? E ao ler de canal fechado?
✅ Correta! Bloqueia (deadlock se ninguém jamais ler); canal fechado entrega zero value com ok=false.
5. Adapte o worker pool para parar limpo quando ctx for cancelado (select).
✅ Correta! select { case j, ok := <-jobs: ...; case <-ctx.Done(): return }
6. O que é goroutine?
✅ Correta! Thread leve gerenciada pelo runtime do Go.
7. O que é channel em Go?
✅ Correta! Canal de comunicação entre goroutines.
8. O que é select em Go?
✅ Correta! Permite esperar por múltiplas operações de canal simultaneamente.
9. O que é context.Context em Go?
✅ Correta! Interface que carrega deadlines, cancelamento e valores para propagar entre goroutines.
10. O que é sync.WaitGroup?
✅ Correta! Espera que um grupo de goroutines termine.
11. O que é sync.Mutex?
✅ Correta! Mecanismo de exclusão mútua para proteger dados compartilhados.
12. O que é race detector (go test -race)?
✅ Correta! Ferramenta que detecta condições de corrida (race conditions) em programas Go.
13. O que é slice em Go?
✅ Correta! Array dinâmico com tamanho variável.
14. O que é map em Go?
✅ Correta! Estrutura de dados chave-valor (hash table).
15. O que é struct em Go?
✅ Correta! Conjunto de campos com tipos, similar à struct em C.
16. O que é interface em Go?
✅ Correta! Conjunto de métodos que um tipo deve implementar (satisfação implícita).
17. O que é defer em Go?
✅ Correta! Adia a execução de uma função até o retorno da função atual (comum para fechar arquivos).
18. O que é panic e recover em Go?
✅ Correta! Panic: erro fatal que interrompe a execução; Recover: recupera um panic (similar a try/catch).
19. O que é goroutine leak?
✅ Correta! Goroutine que nunca termina, consumindo recursos indefinidamente.
20. O que é channel buffer (canal com buffer)?
✅ Correta! Canal que armazena mensagens em um buffer, não bloqueando o envio até que o buffer esteja cheio.
21. O que é goroutine scheduler?
✅ Correta! Componente do runtime Go que distribui goroutines entre threads do SO.
22. O que é GOPATH e Go Modules?
✅ Correta! GOPATH: antiga estrutura de workspace; Go Modules: sistema moderno de gerenciamento de dependências.
23. O que é pprof em Go?
✅ Correta! Ferramenta de profiling para CPU, memória e alocações.
24. O que é garbage collector (GC) em Go?
✅ Correta! Coletor de lixo que libera memória automaticamente.
25. O que é embed em Go 1.16+?
✅ Correta! Diretiva que permite embutir arquivos estáticos no binário.
