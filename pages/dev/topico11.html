2. Lista Ligada

typedef struct No {
    int valor;
    struct No *prox;
} No;

No *push_front(No *head, int v) {
    No *n = malloc(sizeof *n);
    n->valor = v;
    n->prox = head;
    return n;
}

int busca(No *head, int v) {
    for (No *p = head; p; p = p->prox)
        if (p->valor == v) return 1;
    return 0;
}

void libera(No *head) {
    while (head) {
        No *t = head->prox;
        free(head);
        head = t;
    }
}
  • Array = bloco contíguo (cache adora, inserir no meio dói)
  • Lista = nós espalhados ligados por ponteiros (inserir é religar setas, mas cada salto é um cache miss)

3. Pilha e Fila

Pilha (LIFO)

typedef struct {
    int *dados;
    int topo;
    int capacidade;
} Pilha;

void push(Pilha *p, int v) {
    p->dados[++p->topo] = v;
}

int pop(Pilha *p) {
    return p->dados[p->topo--];
}

Usos: undo, call stack, parser de parênteses.

Fila (FIFO)

typedef struct {
    int *dados;
    int ini, fim;
    int capacidade;
} Fila;

void enqueue(Fila *f, int v) {
    f->dados[f->fim++] = v;
    f->fim %= f->capacidade;  /* circular */
}

int dequeue(Fila *f) {
    int v = f->dados[f->ini++];
    f->ini %= f->capacidade;
    return v;
}

Usos: filas de tarefas, BFS, mensageria.

4. Hash Table — O Dicionário O(1)

#define CAP 1024

typedef struct Par {
    char chave[32];
    int valor;
    struct Par *prox;
} Par;

Par *tabela[CAP];

unsigned hash(const char *s) {
    unsigned h = 5381;
    while (*s) h = h * 33 + (unsigned char)*s++;
    return h % CAP;
}
  • Colisões resolvidas por encadeamento (cada bucket é uma listinha)
  • Com bom hash e fator de carga controlado → O(1) em média
  • Casa dos pombos garante colisões; o design as torna raras e baratas

5. Árvore Binária de Busca (BST)

typedef struct NoA {
    int v;
    struct NoA *esq, *dir;
} NoA;

NoA *inserir(NoA *r, int v) {
    if (!r) {
        r = malloc(sizeof *r);
        r->v = v;
        r->esq = r->dir = NULL;
        return r;
    }
    if (v < r->v) r->esq = inserir(r->esq, v);
    else r->dir = inserir(r->dir, v);
    return r;
}
  • BST: menores à esquerda, maiores à direita → busca desce um ramo
  • Balanceada (AVL/rubro-negra): altura = O(log n)
  • Percursos: em-ordem (sai ordenado!), pré-ordem, pós-ordem

6. Heap e Grafos

Heap (Fila de Prioridade)

  • Árvore quase completa em array
  • Filhos de i: 2i+1 e 2i+2
  • Pai ≥ filhos (max-heap)
  • Topo O(1); inserir/remover O(log n)

Grafos — Representação

  • Lista de adjacência: espaço O(V+E), padrão para grafos esparsos
  • Matriz V×V: aresta em O(1), espaço O(V²)

📝 Exercícios — 25 questões

1. Implemente No *remove_valor(No *head, int v) na lista ligada.
✅ Correta! Caso especial se head->valor == v (retorne head->prox após free); senão ande com p->prox.
2. Valide parênteses/colchetes/chaves de uma expressão com uma pilha.
✅ Correta! Abre → push; fecha → pop e confira o par; fim: pilha vazia.
3. Por que a fila circular usa % capacidade? O que quebra sem isso?
✅ Correta! Reusar o espaço do início; sem o módulo, fim estoura o array com a fila meio vazia.
4. Insira 5, 3, 8, 1, 4 numa BST e escreva o percurso em-ordem. O que você nota?
✅ Correta! 1 3 4 5 8 — em-ordem sai ordenado.
5. Num sistema de cache chave→valor com milhões de consultas/s, qual estrutura e por quê?
✅ Correta! Hash table: O(1) médio por operação.
6. Quando uma BST degenera em lista? Qual o custo de busca nesse caso?
✅ Correta! Inserção já ordenada (1,2,3,...) → altura n → busca O(n).
7. Qual a diferença entre pilha e fila?
✅ Correta! Pilha: LIFO (último a entrar, primeiro a sair); Fila: FIFO (primeiro a entrar, primeiro a sair).
8. Qual a complexidade de inserir no início de uma lista ligada?
✅ Correta! O(1)
9. Qual a complexidade de acessar o elemento do meio de uma lista ligada?
✅ Correta! O(n)
10. Qual a complexidade de buscar em uma hash table bem projetada?
✅ Correta! O(1) em média
11. O que é uma colisão em hash table?
✅ Correta! Quando duas chaves diferentes produzem o mesmo índice de hash.
12. Quais são as duas formas principais de resolver colisões em hash table?
✅ Correta! Encadeamento (listas ligadas) e endereçamento aberto (linear probing).
13. Qual a estrutura de dados usada para implementar undo/redo?
✅ Correta! Pilha (LIFO).
14. Qual a estrutura de dados usada para implementar uma fila de impressão?
✅ Correta! Fila (FIFO).
15. O que é fator de carga em uma hash table?
✅ Correta! número de elementos / capacidade. Normalmente mantido abaixo de 0.75.
16. Qual a complexidade de inserção em uma árvore AVL?
✅ Correta! O(log n)
17. Qual a diferença entre árvore binária e árvore binária de busca?
✅ Correta! BST tem a propriedade de ordenação: valores à esquerda < raiz < valores à direita.
18. Qual estrutura é melhor para um cache LRU?
✅ Correta! Hash table + lista duplamente ligada (para manter ordem de uso).
19. O que é grafo direcionado?
✅ Correta! Grafo onde as arestas têm direção (sentido).
20. O que é grafo não-direcionado?
✅ Correta! Grafo onde as arestas não têm direção.
21. Qual a complexidade de inserir no meio de uma lista ligada (dado o nó anterior)?
✅ Correta! O(1) (com o ponteiro para o nó anterior)
22. Qual a complexidade de inserir no meio de um array?
✅ Correta! O(n) (desloca elementos)
23. O que é árvore rubro-negra?
✅ Correta! Árvore binária de busca auto-balanceada (usada em Java TreeMap, C++ std::map).
24. Qual estrutura de dados é usada no algoritmo de Dijkstra para prioridade?
✅ Correta! Heap (fila de prioridade).
25. Qual a complexidade de espaço de uma lista de adjacência para um grafo com V vértices e E arestas?
✅ Correta! O(V + E)
