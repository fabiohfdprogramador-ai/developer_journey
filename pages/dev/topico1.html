🐧 Linux e o Terminal — Sua Nova Casa

Viva no terminal: navegue, manipule arquivos, entenda permissões e encadeie comandos.

1. Navegação e Arquivos

O Linux é um sistema operacional onde tudo é arquivo — configurações, dispositivos, processos. Os caminhos principais:

  • / — raiz do sistema
  • /home — diretórios dos usuários
  • /etc — arquivos de configuração
  • /var/log — logs do sistema
  • /usr/bin — programas executáveis

Comandos essenciais

pwd                         # onde estou
ls -la                      # lista tudo com detalhes
cd projetos                 # entra na pasta (cd .. sobe; cd ~ vai para home)
mkdir -p app/src            # cria árvore de pastas
cp a.txt b.txt              # copia (cp -r para pastas)
mv b.txt notas.txt          # move/renomeia
rm notas.txt                # remove (rm -r pasta/ - sem lixeira!)
cat arquivo.txt             # mostra conteúdo
less                        # para paginar
head/tail                   # para pontas

💡 Dica de ouro

Uma tarefa por dia que você faria no mouse, faça no terminal. Em 30 dias, o terminal deixa de ser obstáculo e vira alavanca.

2. Permissões

ls -l mostra algo como -rwxr-xr--:

  • dono: ler/escrever/executar (rwx)
  • grupo: ler/executar (r-x)
  • outros: só ler (r--)

Modificando permissões

chmod +x script.sh          # torna executável
chmod 644 config.txt        # rw- r-- r-- (6=rw, 4=r, 7=rwx)
sudo comando                # executa como administrador
NúmeroPermissão
7rwx (ler + escrever + executar)
6rw- (ler + escrever)
5r-x (ler + executar)
4r-- (só ler)

3. Pipes e Redirecionamento — A Superpotência

A saída de um comando vira entrada do próximo com |; > grava em arquivo (>> anexa); 2> redireciona erros.

cat access.log | grep "500" | wc -l   # quantas linhas com 500
ps aux | grep node                   # processos do node
history | tail -20                   # últimos 20 comandos
sort nomes.txt | uniq -c | sort -rn > top.txt   # ranking de frequência

4. Seu Primeiro Script

#!/bin/bash
# backup.sh - compacta uma pasta com data no nome
set -euo pipefail
ORIGEM=${1:?uso: backup.sh <pasta>}
DESTINO="backup-$(date +%F).tgz"
tar -czf "$DESTINO" "$ORIGEM"
echo "OK: $DESTINO ($(du -sh "$DESTINO" | cut -f1))"

chmod +x backup.sh && ./backup.sh projetos — automação de verdade em 7 linhas.

📝 Exercícios — 25 questões

1. Crie a árvore lab/{src,logs,backup} com um único comando.
✅ Correta! mkdir -p lab/{src,logs,backup}
2. Gere um arquivo com a lista de todos os .md do seu home.
✅ Correta! find ~ -name "*.md" > lista.txt
3. Conte quantos processos do seu usuário estão rodando agora.
✅ Correta! ps -u $USER | wc -l
4. O que significa a permissão 755 em um script? Escreva-a em rwx.
✅ Correta! rwxr-xr-x — dono tudo; grupo e outros leem/executam.
5. Encadeie: das 100 últimas linhas de um log, as que contêm "error", ordenadas, sem repetição.
✅ Correta! tail -100 app.log | grep error | sort | uniq
6. Modifique o backup.sh para aceitar o destino como 2º parâmetro opcional (padrão: diretório atual).
✅ Correta! DEST_DIR=${2:-.} && use "$DEST_DIR/$DESTINO" no tar.
7. Como ver o conteúdo de um arquivo grande paginado?
✅ Correta! less arquivo.txt (ou more)
8. Como redirecionar a saída de erro de um comando para um arquivo?
✅ Correta! comando 2> erros.txt
9. Qual o comando para ver as últimas 50 linhas de um arquivo de log?
✅ Correta! tail -50 arquivo.log
10. Como criar um arquivo vazio chamado novo.txt?
✅ Correta! touch novo.txt
11. Como copiar uma pasta inteira com todo seu conteúdo?
✅ Correta! cp -r pasta_origem pasta_destino
12. Como listar todos os arquivos (inclusive ocultos) com detalhes?
✅ Correta! ls -la
13. O que faz o comando chmod 644 config.txt?
✅ Correta! Dá permissão rw-r--r--: dono lê/escreve, grupo e outros só leem.
14. Como ver o histórico dos comandos que você executou?
✅ Correta! history
15. Como exibir as primeiras 10 linhas de um arquivo?
✅ Correta! head -10 arquivo.txt
16. Como contar o número de linhas de um arquivo?
✅ Correta! wc -l arquivo.txt
17. Como mover um arquivo para outro diretório?
✅ Correta! mv arquivo.txt /caminho/destino/
18. Como remover uma pasta e todo seu conteúdo de forma recursiva?
✅ Correta! rm -r pasta/ (cuidado: sem lixeira!)
19. Como ver o caminho completo do diretório atual?
✅ Correta! pwd
20. Como buscar todos os arquivos .conf no sistema?
✅ Correta! find / -name "*.conf" 2>/dev/null
21. Como contar quantas vezes a palavra "error" aparece em um log?
✅ Correta! grep -c "error" log.txt ou grep "error" log.txt | wc -l
22. Como ver os processos em execução ordenados por uso de CPU?
✅ Correta! ps aux --sort=-%cpu ou top (pressione P)
23. Como matar um processo pelo PID?
✅ Correta! kill PID (ou kill -9 PID para forçar)
24. Como ver o espaço em disco disponível?
✅ Correta! df -h
25. Como ver o tamanho de um diretório e seus subdiretórios?
✅ Correta! du -sh pasta/
