🏗️ Terraform e Infraestrutura como Código

Sair do console: infraestrutura declarada, versionada e revisada em PR — com o modelo mental de estado que evita os acidentes clássicos.

1. O Modelo Mental

  • Declarativo: você descreve o que quer, não como fazer
  • State: mapeia o declarado → o real
  • Providers: AWS, GCP, Azure, Kubernetes, etc.
  • Resources: os componentes da infraestrutura
resource "aws_s3_bucket" "artifacts" {
    bucket = "minhaempresa-artifacts"
    tags = { team = "platform" }
}

resource "aws_db_instance" "app" {
    engine = "postgres"
    instance_class = "db.t4g.micro"
    allocated_storage = 20
}

2. Fluxo

terraform init      # baixa providers e inicializa
terraform plan      # mostra o que vai mudar (LEIA!)
terraform apply     # aplica as mudanças
terraform destroy   # destrói tudo (CUIDADO!)
  • State remoto (S3 + DynamoDB lock) — nunca no laptop!
  • Módulos: empacotam padrões reutilizáveis
  • Workspaces/vars: separam dev/prod

3. Práticas

  • Quem clicou no console criou drift — mudança só por PR
  • Plan no CI: denuncia divergências
  • Least privilege: IAM com permissões mínimas

💡 Sua missão AWS: recriar via Terraform o que você já usa (VPC, subnets, SGs, ECS/EKS, RDS, S3, IAM).

📝 Exercícios — 25 questões

1. Por que state remoto com lock é inegociável em time?
✅ Correta! Dois applies simultâneos corrompem o mapa do mundo; lock serializa, remoto compartilha.
2. O que um plan com "1 to destroy" inesperado indica e o que fazer?
✅ Correta! Você está prestes a apagar algo real (renomeou recurso?); investigue antes do apply (moved blocks/import).
3. Alguém alterou um SG no console. Como o Terraform reage no próximo plan e como reconciliar?
✅ Correta! Detecta drift e propõe reverter; ou você importa/ajusta o código para adotar a mudança — decisão consciente, em PR.
4. O que é Terraform?
✅ Correta! Ferramenta de Infrastructure as Code (IaC) para criar e gerenciar infraestrutura.
5. O que é HCL (HashiCorp Configuration Language)?
✅ Correta! Linguagem declarativa usada no Terraform para definir recursos.
6. O que é state no Terraform?
✅ Correta! Arquivo que mapeia os recursos declarados para os recursos reais na nuvem.
7. O que é provider no Terraform?
✅ Correta! Plugin que permite gerenciar recursos de um serviço (AWS, GCP, Azure, etc).
8. O que é resource no Terraform?
✅ Correta! Componente de infraestrutura que será criado (ex: EC2, S3, RDS).
9. O que é module no Terraform?
✅ Correta! Pacote reutilizável de recursos Terraform.
10. O que é variable no Terraform?
✅ Correta! Parâmetro de entrada para configurações, permite reuso e parametrização.
11. O que é output no Terraform?
✅ Correta! Valor de saída que pode ser usado por outros módulos ou exibido no console.
12. O que é terraform init?
✅ Correta! Comando que inicializa um diretório de trabalho Terraform e baixa providers.
13. O que é terraform plan?
✅ Correta! Comando que mostra as mudanças que serão aplicadas (execução dry-run).
14. O que é terraform apply?
✅ Correta! Comando que aplica as mudanças descritas na configuração.
15. O que é terraform destroy?
✅ Correta! Comando que destrói todos os recursos gerenciados pelo Terraform.
16. O que é drift no contexto do Terraform?
✅ Correta! Diferença entre o estado real e o estado declarado (causada por mudanças manuais).
17. O que é state locking?
✅ Correta! Mecanismo que impede múltiplos usuários de modificar o state simultaneamente.
18. O que é remote state?
✅ Correta! State armazenado remotamente (ex: S3) para compartilhamento e backup.
19. O que é terraform workspace?
✅ Correta! Mecanismo para gerenciar múltiplos ambientes (dev, staging, prod) com o mesmo código.
20. O que é terraform import?
✅ Correta! Comando que importa um recurso existente para o state do Terraform.
21. O que é terraform fmt?
✅ Correta! Comando que formata arquivos Terraform no estilo padrão.
22. O que é terraform validate?
✅ Correta! Comando que valida a sintaxe das configurações Terraform.
23. O que é data source no Terraform?
✅ Correta! Permite consultar dados de recursos existentes (não gerenciados pelo Terraform).
24. O que é lifecycle no Terraform?
✅ Correta! Bloco que controla comportamento do ciclo de vida do recurso (create_before_destroy, prevent_destroy).
25. O que é IaC (Infrastructure as Code)?
✅ Correta! Prática de gerenciar infraestrutura usando código em vez de processos manuais.
