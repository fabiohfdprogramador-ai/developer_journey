🔧 Funções e Escopo

Quebrar programas em funções, entender protótipos, passagem por valor e escopo — e a pilha de chamadas que explica a recursão.

1. Anatomia de uma Função

#include <stdio.h>

int soma(int a, int b);  /* protótipo: avisa o compilador antes do uso */

int main(void) {
    printf("%d\n", soma(2, 3));  /* 5 */
    return 0;
}

int soma(int a, int b) {  /* definição */
    return a + b;
}
  • Protótipo: declara a função antes do uso
  • Definição: o corpo da função com a lógica
  • Parâmetros: variáveis que a função recebe
  • Retorno: valor devolvido (ou void se não retorna nada)

2. Por Valor — A Regra que Muda Tudo

Em C, argumentos são copiados. A função recebe cópias; mexer nelas não afeta as originais:

void tenta_dobrar(int x) {
    x = x * 2;  /* dobra a CÓPIA */
}

int n = 10;
tenta_dobrar(n);
printf("%d\n", n);  /* 10 - inalterado */

💡 Para alterar de verdade, passa-se o endereço (capítulo de ponteiros).

3. Escopo e Vida Útil

  • Variável local: nasce na chamada e morre no retorno (vive na stack)
  • Variável global: existe o programa todo — use com parcimônia
  • static dentro de função: mantém o valor entre chamadas
int global = 10;  /* global - visível em todo o arquivo */

void contador() {
    static int calls = 0;  /* mantém valor entre chamadas */
    calls++;
    printf("Chamada nº %d\n", calls);
}

4. Recursão

long fatorial(int n) {
    if (n <= 1) return 1;  /* caso base — sem ele, stack overflow */
    return n * fatorial(n - 1);  /* passo: reduz o problema */
}

Como funciona a recursão do fatorial(5):

fatorial(5)
  → 5 * fatorial(4)
  → 5 * 4 * fatorial(3)
  → 5 * 4 * 3 * fatorial(2)
  → 5 * 4 * 3 * 2 * fatorial(1)
  → 5 * 4 * 3 * 2 * 1
  → 120

5. A Pilha de Chamadas (Call Stack)

A pilha de chamadas é uma estrutura LIFO (último a entrar, primeiro a sair) que gerencia as chamadas de função:

main()
fatorial(5)
fatorial(4)
fatorial(3)
fatorial(2)
fatorial(1) ← topo da pilha

Cada chamada empilha um stack frame com parâmetros, variáveis locais e endereço de retorno. Quando a função retorna, seu frame é desempilhado.

⚠️ Recursão sem caso base → estouro da pilha (stack overflow)

📝 Exercícios — 25 questões

1. Escreva int max3(int a, int b, int c) que retorna o maior dos três.
✅ Correta! int m = a > b ? a : b; return m > c ? m : c;
2. Escreva int eh_primo(int n) que retorna 1 se primo, 0 se não.
✅ Correta! Laço for (int i=2; i*i <= n; i++) if (n%i==0) return 0; (trate n < 2)
3. Por que o programa da seção 2 imprime 10 e não 20?
✅ Correta! Passagem por valor: a função altera uma cópia do valor.
4. Escreva long fib(int n) recursiva. Por que para n=50 ela fica lenta?
✅ Correta! Recalcula os mesmos subproblemas exponencialmente (fib(48) duas vezes, fib(47) três...).
5. O que acontece se remover o caso base da recursão?
✅ Correta! Chamadas infinitas → estouro da pilha (stack overflow).
6. O que é um protótipo de função?
✅ Correta! Declaração da função que informa ao compilador seu nome, tipo de retorno e parâmetros.
7. O que é uma variável local?
✅ Correta! Variável declarada dentro de uma função, visível apenas dentro dela.
8. O que é uma variável global?
✅ Correta! Variável declarada fora de qualquer função, visível em todo o arquivo.
9. O que faz a palavra-chave static dentro de uma função?
✅ Correta! Mantém o valor da variável entre chamadas da função.
10. O que é a pilha de chamadas (call stack)?
✅ Correta! Estrutura que gerencia as chamadas de função, armazenando parâmetros e variáveis locais.
11. O que acontece com as variáveis locais quando uma função retorna?
✅ Correta! São destruídas (liberadas da pilha).
12. O que é um stack frame?
✅ Correta! Bloco de dados na pilha que contém parâmetros, variáveis locais e endereço de retorno de uma função.
13. Escreva uma função int soma_recursiva(int n) que soma de 1 até n usando recursão.
✅ Correta! if (n <= 0) return 0; return n + soma_recursiva(n - 1);
14. Qual a diferença entre void e int como tipo de retorno?
✅ Correta! void não retorna valor; int retorna um inteiro.
15. O que é recursão de cauda (tail recursion)?
✅ Correta! Quando a chamada recursiva é a última operação da função. Alguns compiladores otimizam para evitar stack overflow.
16. Escreva int soma_digitos(int n) que soma os dígitos de um número usando recursão.
✅ Correta! if (n < 10) return n; return (n % 10) + soma_digitos(n / 10);
17. O que é overflow de pilha?
✅ Correta! Quando a pilha de chamadas excede seu tamanho máximo, geralmente por recursão infinita.
18. Uma função pode chamar a si mesma? Como isso se chama?
✅ Correta! Sim, chama-se recursão.
19. O que é uma função pura?
✅ Correta! Função que sempre retorna o mesmo valor para os mesmos argumentos e não tem efeitos colaterais.
20. Como passar um array para uma função em C?
✅ Correta! Passa-se o ponteiro para o primeiro elemento (o array decai para ponteiro).
21. Qual a saída do código abaixo?
int x = 5; int y = 10; troca(x, y); printf("%d %d", x, y);
✅ Correta! 5 10 — passagem por valor não altera as variáveis originais.
22. O que o compilador faz ao encontrar um protótipo de função?
✅ Correta! Verifica se as chamadas à função estão corretas (número e tipo de argumentos).
23. Escreva uma função recursiva que calcula a potência base^expoente.
✅ Correta! if (exp == 0) return 1; return base * potencia(base, exp - 1);
24. O que é função inline?
✅ Correta! Função cujo código é inserido no local da chamada, evitando overhead de chamada (sugestão ao compilador).
25. O que é efeito colateral em uma função?
✅ Correta! Quando a função modifica algo fora de seu escopo (ex: variável global, arquivo, tela).
