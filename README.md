- ✅ Respostas com feedback visual (verde/vermelho)

## 🛠️ Como usar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Selecione um tópico na barra lateral
4. Estude o conteúdo e faça os exercícios
5. Clique em "Ver resposta" para conferir
